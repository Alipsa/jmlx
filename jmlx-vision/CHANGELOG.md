# Changelog

## [0.1.2] - 2026-11-22

Date denotes the version cut, not publication to Maven Central.

### Changed

- No functional source changes from `0.1.1`. The POM and Javadoc carry the new version;
  the POM and module metadata now depend on Jackson 3.3.0 (was 3.1.2), and the `.module`
  is generated by Gradle 9.9.0 (was 9.7.0) under the Phase 8.4 combined release toolchain.
